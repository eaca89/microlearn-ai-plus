# ساخت انیمیشن با هوش مصنوعی: سه روش با Claude

فایل‌ها و پرامپت‌های ویدیوی «ساخت انیمیشن با هوش مصنوعی: سه روش با Claude» از میکرولرن.
یه مثال واحد (افسانهٔ ده هزار قدم) با سه ابزار ساخته می‌شه: **Remotion**، **HyperFrames** و **Three.js**، همه با Claude Code (یا Codex).

- آپارات: _به‌زودی_
- یوتیوب (Microlearn AI Plus): https://youtu.be/IuBHrSyA_u4

## پیش‌نیازها
- بلد باشی توی Claude Code یه پوشه باز کنی و پرامپت بدی (Codex هم کار می‌کنه)
- Claude Code با پلن پولی Claude
- کامپیوتر ویندوز، مک یا لینوکس؛ برای سه‌بعدی یه کارت گرافیک معمولی

## پرامپت‌ها
هر پرامپت رو توی یه پوشهٔ خالی به Claude Code بده. بعد از نصب اسکیل‌ها، یه جلسهٔ تازه باز کن.

### ۱. نصب Remotion

```text
یه پروژه‌ی Remotion خالی توی همین پوشه بساز.
اگه Node.js نصب نیست، اول نسخه‌ی LTS رو نصب کن.
بعد اسکیل‌های رسمی Remotion رو با npx skills add remotion-dev/skills نصب کن.
آخرش بگو برای باز کردن Remotion Studio چه دستوری بزنم.
```

### ۲. ده هزار قدم با Remotion

```text
با Remotion یه انیمیشن ۲۰ ثانیه‌ای بساز، ۱۹۲۰ در ۱۰۸۰، ۳۰ فریم در ثانیه.
موضوع: افسانه‌ی ده هزار قدم.
سبک: پس‌زمینه‌ی سرمه‌ای تیره، رنگ تأکید نارنجی، فونت Vazirmatn، متن‌ها راست‌چین.
۰ تا ۴ ثانیه: عدد ۱۰٬۰۰۰ بزرگ وسط تصویر میاد، بعد یه خط روش کشیده می‌شه.
۴ تا ۱۰ ثانیه: یه محور افقی قدم‌ها؛ نقطه‌های ۲٬۰۰۰ و ۷٬۰۰۰ و ۱۰٬۰۰۰ یکی‌یکی روش میان.
۱۰ تا ۱۶ ثانیه: منحنی خطر از ۲٬۰۰۰ تا ۷٬۰۰۰ تند پایین میاد و بعد تقریباً صاف می‌شه؛ برچسب «حدود نصف» روی ۷٬۰۰۰.
۱۶ تا ۲۰ ثانیه: جمله‌ی آخر: «هفت هزار قدم هم کافیه».
همه‌ی متن‌ها و عددها رو توی یه فایل جدا به اسم data.json بذار.
```

### ۳. نصب HyperFrames

```text
HyperFrames رو توی همین پوشه راه بنداز.
اول چک کن Node.js نسخه‌ی ۲۲ یا بالاتر و FFmpeg نصب باشن؛ اگه نیستن، نصبشون کن.
بعد اسکیل‌هاش رو با npx skills add heygen-com/hyperframes نصب کن.
آخرش یه پروژه‌ی خالی HyperFrames بساز.
```

### ۴. زوم‌اوت ده هزار قدم با HyperFrames

```text
/hyperframes
یه ویدیوی ۲۰ ثانیه‌ای ۱۹۲۰ در ۱۰۸۰ از افسانه‌ی ده هزار قدم بساز، با یه حرکت پیوسته‌ی زوم به عقب.
۰ تا ۴ ثانیه: فقط یه رد پا وسط یه خونه از تقویم، با عدد «۱ قدم».
۴ تا ۹ ثانیه: دوربین عقب میاد؛ یه روز کامل، شمارنده تا ۷٬۰۰۰ بالا می‌ره.
۹ تا ۱۴ ثانیه: باز عقب‌تر؛ یه ماه تقویم، هر روز یه ستون کوچیک قدم.
۱۴ تا ۲۰ ثانیه: کل تصویر می‌شه یه نمودار: فایده تا ۷٬۰۰۰ تند بالا می‌ره و بعد تقریباً صاف می‌شه.
سبک: پس‌زمینه‌ی کرمی، رنگ تأکید سبز، فونت Vazirmatn، حرکت‌ها نرم.
آخرش رندر بگیر و MP4 رو بده.
```

### ۵. نصب Three.js

```text
یه پروژه‌ی Three.js توی همین پوشه بساز که بشه صحنه رو به ویدیو تبدیل کرد.
Three.js رو نصب کن و یه سیستم ضبط بساز که صحنه رو فریم‌به‌فریم، ۳۰ فریم در ثانیه، بگیره و با FFmpeg بکنه MP4.
اگه برای ضبط به ابزار اضافه‌ای نیاز بود، اول از من بپرس.
```

### ۶. ده هزار قدم سه‌بعدی با Three.js

```text
با Three.js یه انیمیشن سه‌بعدی ۲۰ ثانیه‌ای بساز، ۱۹۲۰ در ۱۰۸۰، ۳۰ فریم در ثانیه.
۰ تا ۴ ثانیه: یه پنل شیشه‌ای مات با عدد ۱۰٬۰۰۰ توی تاریکی؛ یه نور نارنجی آروم روش می‌چرخه.
۴ تا ۸ ثانیه: پنل ترک برمی‌داره و تیکه‌تیکه می‌شه.
۸ تا ۱۴ ثانیه: دوربین از بین تیکه‌ها رد می‌شه و می‌رسه به یه رودخونه از ذره‌های نورانی.
۱۴ تا ۲۰ ثانیه: ذره‌ها کنار هم می‌شینن و یه منحنی می‌سازن که تا ۷٬۰۰۰ تند بالا می‌ره و بعد صاف می‌شه؛ عدد ۷٬۰۰۰ روش روشن می‌شه.
دوربین بین صحنه‌ها پیوسته حرکت کنه و خود اجزا هم آروم تکون بخورن.
هر جا مناسبه از شیدر استفاده کن. سبک: شیشه‌ی مات و ذره‌های نارنجی.
فرض کن این نمونه‌کار اصلیت برای یه موقعیت شغلی موشن‌دیزاینه.
بعد از ساخت، از چند تا فریم عکس بگیر، نگاهشون کن و هر مشکلی دیدی درست کن؛ آخرش رندر بگیر.
```
