# هوش مصنوعی کد می‌نویسه؛ پس برنامه‌نویس به چه دردی می‌خوره؟

فایل‌های ویدیوی میکرولرن: چهار مهارتی که شرکت‌ها الان از برنامه‌نویس می‌خوان (بررسی کد، قضاوت، مدیریت ایجنت‌ها، ارتباط) و تمرین هر کدوم.

## فایل‌ها
- `decisions.md` — قالب دفترچهٔ تصمیم (تمرین مهارت دوم: قضاوت)
- `spec-example.md` — نمونهٔ اسپک برای ایجنت، از مثال نوبت‌دهی کلینیک (تمرین مهارت سوم)
- `pull-request-template.md` — قالب چهارخطی توضیح تغییرات (تمرین مهارت چهارم: ارتباط)
- `review-checklist.md` — چک‌لیست بررسی کدی که هوش مصنوعی نوشته (تمرین مهارت اول)
- `SOURCES.md` — منبع همهٔ عددهای ویدیو

## تمرین‌ها، خلاصه
1. **بررسی کد:** یه پروژهٔ متن‌باز توی گیت‌هاب پیدا کن، یکی از تغییراتش (diff) رو قبل از اجرا بخون، حدس بزن باگ کجاست، بعد تست‌ها رو اجرا کن.
2. **قضاوت:** کنار پروژه‌ات فایل `decisions.md` بذار و برای هر تصمیم مهم گزینه‌ها و دلیلت رو بنویس.
3. **مدیریت ایجنت‌ها:** یه ابزار (Claude Code، Cursor یا Codex) رو عمیق یاد بگیر؛ بعد خط تولید بساز: اسپک، ایجنت سازنده، ایجنت بررسی‌کننده، تست.
4. **ارتباط:** قبل از کد زدن چهار خط بنویس: چی عوض می‌شه، چرا، چطور تستش می‌کنی، کجاش مطمئن نیستی.
