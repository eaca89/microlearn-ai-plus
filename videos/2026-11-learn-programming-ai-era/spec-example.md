# اسپک: رزرو نوبت با پیش‌پرداخت

## هدف
بیمار آنلاین نوبت می‌گیره و همون‌جا پیش‌پرداخت می‌ده.

## قانون‌ها
1. هر نوبت فقط یه صاحب داره، حتی اگه دو نفر هم‌زمان رزروش کنن (رقابت هم‌زمان / race condition).
2. هر نفر پیش هر دکتر فقط یه نوبتِ باز داره.
3. ساعت گذشته و روزهای تعطیل قابل رزرو نیستن.
4. پنجشنبه‌ها بعدازظهر نوبت داده نمی‌شه.
5. اگه درگاه پرداخت جواب نده (timeout)، نوبت ثبت نمی‌شه و پولی کم نمی‌شه؛ نوبت دوباره آزاد می‌شه.
6. لغو تا ۲۴ ساعت قبل: پول برمی‌گرده.

## تست‌هایی که باید باشن
- دو رزرو هم‌زمان برای یه نوبت → فقط یکی قبول می‌شه.
- رزرو ساعت گذشته / روز تعطیل / پنجشنبه بعدازظهر → رد می‌شه.
- درگاه پرداخت جواب نمی‌ده → نوبت آزاد می‌مونه.
- نفری که یه نوبت باز داره دوباره پیش همون دکتر رزرو می‌کنه → رد می‌شه.

## خط تولید
اسپک → ایجنت سازنده → ایجنت بررسی‌کننده (کار رو با همین اسپک مقایسه می‌کنه) → همهٔ تست‌ها سبز → اضافه شدن به کد اصلی.
