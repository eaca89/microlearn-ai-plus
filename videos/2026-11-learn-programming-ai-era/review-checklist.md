# چک‌لیست بررسی کدی که هوش مصنوعی نوشته

قبل از اجرا، کد رو مثل کدی بخون که یه همکار برات فرستاده.

- [ ] **حالت‌های مرزی (edge case):** ورودی خالی، صفر، منفی، ساعت گذشته، روز تعطیل.
- [ ] **رقابت هم‌زمان (race condition):** اگه دو نفر دقیقاً با هم همین کار رو بکنن چی می‌شه؟
- [ ] **تایم‌اوت (timeout):** اگه یه سرویس بیرونی (درگاه پرداخت، پیامک) جواب نده، وضعیت چی می‌مونه؟
- [ ] **تست‌ها:** فقط حالت خوب رو تست کردن یا حالت‌های بد هم هست؟ تست‌ها رو خود ایجنت نوشته؟
- [ ] **دیتابیس:** جستجوها index دارن؟ با هزاران کاربر هم‌زمان کند نمی‌شه؟
- [ ] **اسپک:** کد دقیقاً همون کاری رو می‌کنه که اسپک گفته؟
