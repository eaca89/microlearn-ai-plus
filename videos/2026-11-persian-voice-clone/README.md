# صدای خودت رو با هوش مصنوعی بساز: متن فارسی به گفتار در گوگل کولب

نوت‌بوکِ ویدیوی «صدای خودت رو با هوش مصنوعی بساز» از میکرولرن.
متن فارسی می‌دی و یه فایل صوتی تحویل می‌گیری، با صدایی که از یه کلیپ ۱۰ تا ۱۵ ثانیه‌ای از صدای خودت تقلید شده. مدل: **Chatterbox** با نسخهٔ فارسی‌اش. همه‌چیز رایگان روی GPU کولب اجرا می‌شه؛ نه نصب لازمه، نه کارت گرافیک.

## پیش‌نیازها
- برنامه‌نویسی لازم نیست؛ کدها آماده‌ست
- حساب گوگل و حساب Hugging Face
- یه فایل ۱۰ تا ۱۵ ثانیه‌ای از صدای خودت، بدون موزیک، توی اتاق ساکت

## قدم‌ها
1. **آماده کردن کولب:** Runtime ← Change runtime type ← **T4 GPU**، بعد سلول اول.
2. **نصب و Hugging Face:** نصب Chatterbox؛ توی صفحهٔ مدل فارسی دسترسی بگیر، یه توکن از نوع **Read** بساز و توی کولب، بخش 🔑 **Secrets**، با اسم `HF_TOKEN` بذار. توکن رو هیچ‌وقت مستقیم توی کد ننویس.
3. **اولین صدای فارسی:** دانلود و لود مدل، ساختن یه جمله با صدای پیش‌فرض.
4. **صدای خودت:** کلیپ مرجع (`ref.wav`) رو آپلود کن و همون جمله رو با صدای خودت بساز.
5. **متن بلند و لحن:** متن بلند خودکار سر نقطه و علامت سؤال تیکه می‌شه (هر تیکه زیر ۲۰۰ حرف). لحن رو با علامت‌های نگارشی، عدد `exaggeration` (مثلاً ۰٫۸ = پرانرژی‌تر) و از همه مؤثرتر، خود کلیپ مرجع کنترل کن. سلول آخر فایل رو دانلود می‌کنه.
